# md5volume
코드그라운드 최악의 볼륨조절 ui 제작 출품작

---

안녕하세요. Veritasium 한국어 채널을 통해 컨테스트 정보를 접하고
3초만에 떠오른 아이디어를 구현해 올립니다.

대충 추억의 MD5 배틀을 볼륨 조절과 접목한 것입니다.
동작은 이렇습니다. 텍스트를 입력하면 MD5 해시를 계산하고, 해시 끝 두 자리로 볼륨이 결정됩니다. 원하는 볼륨을 얻으려면 맞는 문자열을 직접 찾아야 합니다.

저는 꽤 오랫동안 백준, 코드포스를 비롯한 Problem Solving, Competitive Programming을 했었습니다. C++로요. 그래서 HTTP 웹 서버와 MD5 알고리즘 구현을 C++로 구현해서 작성했습니다(저 말고, Gemma랑 Claude가요). 그래서 파일도 딱 하나입니다. 백준에서 제출을 프로젝트 단위로 올리는 거 본 적 있으신가요. 일단 저는 없습니다.

컴파일은 g++ (Ubuntu 15.2.0-16ubuntu1) 15.2.0을 썼고, 
실행환경은 WSL2(Ubuntu 26.04 LTS)입니다. 대충 Native Linux에서도 동작하지 않을까요? 아님 말구요.

조금만 손 대면 Windows에서도 돌아가게는 만들 수 있을텐데 귀찮습니다.

감사합니다.
